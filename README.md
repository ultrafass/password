## 📝 Описание
Графическое приложение на Python (tkinter) для генерации надёжных паролей с настраиваемыми параметрами:
- Ползунок длины пароля (4–64 символа)
- Выбор наборов символов: цифры, строчные/заглавные буквы, спецсимволы
- Таблица истории с автоматическим сохранением в JSON
- Валидация входных данных

## 🛠 Требования
- Python 3.6+
- Стандартные библиотеки: `tkinter`, `random`, `json`, `string`, `os`, `datetime`
